Die IdeeThe idea

Ein Export ist noch kein BackupAn export is not yet a backup

Der Export von paperless-ngx ist kein vollständiges System-Backup. Datenbank, Dokumente, Konfiguration und Geheimnisse gehören zusammen und müssen zusammen gesichert werden, sonst lässt sich im Ernstfall nichts sicher wiederherstellen. Dieses Werkzeug soll genau das übernehmen und die Wiederherstellung auf einem neuen, leeren Ziel einfach und prüfbar machen. Es ist kein offizielles paperless-ngx-Projekt.The paperless-ngx export is not a complete system backup. Database, documents, configuration and secrets belong together and must be backed up together, otherwise nothing can be restored reliably in an emergency. This tool is meant to do exactly that and to make restoring onto a new, empty target simple and verifiable. It is not an official paperless-ngx project.

SicherSafe

Kleiner Zugang, erst lesenSmall access, read first

Der Zugang zum paperless-LXC läuft über SSH mit eigenem Schlüssel und einer kleinen Erlaubnisliste, ohne API-Token. Erst wird nur gelesen, dann geschrieben.Access to the paperless LXC uses SSH with its own key and a small allow-list, no API token. It reads first and only then writes.
