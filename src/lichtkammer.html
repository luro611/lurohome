Die IdeeThe idea

Die Fotos im MittelpunktThe photos at the centre

Eine Fotowebsite mit WordPress bringt viel mit, was man nicht braucht: Plugins, Updates, Datenbank, Angriffsfläche. Lichtkammer macht nur das Nötige. Fotos hochladen, in Galerien ordnen, Seiten schreiben und auf „Veröffentlichen“ klicken. Dann erzeugt Lichtkammer die öffentliche Website als fertige HTML-Dateien. Besucher bekommen schnelle, ruhige Seiten, und auf dem Server läuft beim Ansehen kein Programm.A photo website on WordPress brings a lot you don’t need: plugins, updates, a database, attack surface. Lichtkammer only does what is necessary. Upload photos, arrange them in galleries, write pages and click “Publish”. Lichtkammer then generates the public website as ready-made HTML files. Visitors get fast, calm pages, and no program runs on the server while they look around.

Was Lichtkammer kannWhat Lichtkammer does

Einfach für alle, die Fotos pflegenSimple for everyone who looks after photos

BilderImages

Originale bleiben unberührtOriginals stay untouched

Hochladen in Stücken mit Fortschrittsanzeige, auch bei großen Dateien und knappen Server-Grenzen. Jedes Foto wird einzeln verarbeitet: Varianten in mehreren Größen als AVIF, WebP und JPEG. GPS-Daten werden aus allem Öffentlichen entfernt, die Originale nie überschrieben.Chunked uploads with a progress bar, even for large files and tight server limits. Every photo is processed on its own: variants in several sizes as AVIF, WebP and JPEG. GPS data is removed from everything public, originals are never overwritten.

GalerienGalleries

Ruhig präsentiertCalmly presented

Galerien als Kacheln, gleich hohe Bildreihen und eine Lightbox mit Tastatur, Wischgesten und Bildinfo. Fotografen haben eigene Seiten. Zu jedem Foto gehört ein Alt-Text (Pflicht), damit die Seite für alle lesbar bleibt. Ein Papierkorb und Mehrfachbearbeitung erleichtern die Pflege.Galleries as tiles, rows of equal height and a lightbox with keyboard, swipe gestures and image info. Photographers have their own pages. Every photo needs alt text (required) so the site stays readable for everyone. A trash bin and bulk editing make upkeep easier.

SeitenPages

Mit Blöcken gestaltenBuilt from blocks

Seiten wie „Über uns“ oder Ausstellungen entstehen aus Blöcken: Text, Foto, Raster, Zitat, Knopf, Spalten, Bild und Text, Karussell und Titelbild. Auch die Startseite besteht aus Blöcken. Den Bildausschnitt bestimmst du selbst. Logos, Menü und Fußzeile pflegst du im Admin.Pages such as “About us” or exhibitions are built from blocks: text, photo, grid, quote, button, columns, image and text, carousel and cover image. The home page is built from blocks too. You choose the image crop yourself. Logos, menu and footer are managed in the admin.

VeröffentlichenPublishing

Erst Vorschau, dann livePreview first, then live

Änderungen sind erst nach „Veröffentlichen“ sichtbar. Vorher zeigt die Vorschau die Seite genau so, wie Besucher sie sehen werden. Was noch im Entwurf steckt, nennt Lichtkammer beim Namen. Ist etwas schiefgegangen, nimmt „Rückgängig“ die Veröffentlichung zurück.Changes only become visible after “Publish”. Before that, the preview shows the page exactly as visitors will see it. Lichtkammer names whatever is still in draft. If something went wrong, “Undo” takes the publication back.

AnmeldungSign-in

Passwort plus CodePassword plus code

Anmeldung mit Passwort und einem Code aus einer Authenticator-App (TOTP), dazu Wiederherstellungscodes. Weitere Personen kommen per Einladung dazu, jeder Schritt steht im Protokoll.Sign-in with a password and a code from an authenticator app (TOTP), plus recovery codes. Further people join by invitation, every step is logged.

UmzugMigration

Weg von WordPressAway from WordPress

Ein Exportskript liest eine WordPress-Seite nur aus. Lichtkammer übernimmt Fotos, Galerien, Seiten und Fotografen, meldet fehlende Alt-Texte und leitet alte Adressen weiter, damit Links und Suchmaschinen nichts verlieren.An export script only reads from a WordPress site. Lichtkammer takes over photos, galleries, pages and photographers, reports missing alt texts and redirects old addresses so links and search engines lose nothing.

BetriebHosting

Ein Code, zwei ZuhauseOne codebase, two homes

Webspace mit FTPWeb hosting with FTP

Lichtkammer braucht nur PHP und SQLite. Keine eigene Datenbank, kein SSH, kein Composer und kein Cron auf dem Server. Du lädst ein Zip herunter, entpackst es, spielst es per FTPS hoch, füllst eine kleine Konfigurationsdatei aus und legst im Browser den Administrator an. Eine Anleitung liegt dem Zip bei. Aktualisieren geht durch Überspielen: Konfiguration, Daten und Fotos sind nicht im Zip und bleiben unberührt, die Datenbank aktualisiert sich selbst.Lichtkammer only needs PHP and SQLite. No separate database, no SSH, no Composer and no cron on the server. You download a zip, unpack it, upload it via FTPS, fill in a small configuration file and create the administrator in the browser. Instructions come with the zip. Updating works by uploading over the old installation: configuration, data and photos are not in the zip and stay untouched, and the database updates itself.

DockerDocker

Dasselbe Programm als fertiges Image (ghcr.io/luro611/lichtkammer) mit einer Compose-Datei, zum Beispiel im eigenen LXC hinter einem Reverse Proxy für HTTPS. Aktualisieren: docker compose pull und neu starten. Unterschiede stehen nur in der Konfiguration, nie im Code.The same program as a ready-made image (ghcr.io/luro611/lichtkammer) with a Compose file, for example in your own LXC behind a reverse proxy for HTTPS. Updating: docker compose pull and restart. Differences live only in the configuration, never in the code.

Der NameThe name

Eine Kammer für das LichtA chamber for light

Jede Kamera ist eine Lichtkammer: Licht fällt durch das Objektiv in einen dunklen Raum und wird dort zum Bild. Lichtkammer ist der Raum, in dem deine Bilder danach wohnen.Every camera is a chamber of light: light falls through the lens into a dark space and becomes a picture there. Lichtkammer is the room where your pictures live afterwards.
