Der rote FadenThe common thread

Alles in LXC, damit wenig Hardware reichtEverything in LXC, so little hardware is enough

Im Buch bekommt jede Anwendung ihren eigenen LXC-Container. Ein LXC teilt sich den Kern des Betriebssystems mit dem Proxmox-Host, statt wie eine virtuelle Maschine ein komplettes eigenes System zu starten. Dadurch braucht er deutlich weniger Arbeitsspeicher und Rechenleistung und startet in Sekunden.In the book every application gets its own LXC container. An LXC shares the operating system kernel with the Proxmox host instead of booting a complete system of its own like a virtual machine. That means it needs far less memory and computing power and starts in seconds.

Das macht den Unterschied, wenn der Server nur wenige Kerne und wenig Speicher hat, zum Beispiel ein sparsamer Mini-PC mit Intel N100. Darauf laufen viele Anwendungen nebeneinander, die als einzelne VMs den Rechner schnell überfordern würden. Wo eine VM wirklich besser ist, zeigt das Buch sie als Alternative.That makes the difference when the server has only a few cores and little memory, for example an energy-efficient mini PC with an Intel N100. It can run many applications side by side that would quickly overload the machine as separate VMs. Where a VM really is the better choice, the book shows it as an alternative.
