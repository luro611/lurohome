Rechte im BlickPermissions in focus

Das ProblemThe problem

Wem gehört die Datei wirklich?Who really owns that file?

Wer Proxmox mit LXC-Containern und einem NAS oder gemeinsamen Ordnern betreibt, kennt das: Ein Programm im Container schreibt Dateien, und danach kommt vom Mac oder PC niemand mehr heran. Oder der Container darf in seinen eigenen Ordner nicht schreiben. Schuld ist fast immer die Übersetzung der Benutzer-Nummern (UID/GID) zwischen Container und Host. Benutzer 1000 im Container ist auf dem Host plötzlich 101000, oder er erscheint als „nobody“. Viele lösen das, indem sie den Container privilegiert machen. Das funktioniert, schwächt aber die Abschottung.Anyone running Proxmox with LXC containers and a NAS or shared folders knows this: an app in a container writes files, and afterwards nobody can open them from a Mac or PC. Or the container is not allowed to write to its own folder. The cause is almost always how user numbers (UID/GID) are translated between container and host. User 1000 in the container suddenly becomes 101000 on the host, or shows up as “nobody”. Many people solve this by making the container privileged. That works, but weakens isolation.

ProblemeProblems

Ist alles in Ordnung?Is everything all right?

Nach jedem Einlesen prüft PermLens von selbst bekannte Fehlerquellen: Ordner, die ein Container als „nobody“ sieht, fehlende Mount-Quellen, gemeinsame Ordner ohne setgid, gleiche Namen mit verschiedenen Nummern, NFS mit no_root_squash und mehr. Zu jedem Problem gibt es eine Erklärung, einen Befehl zum Kopieren und die Einstufung harmlos, Vorsicht oder Risiko. Viele Lösungen kann PermLens auch selbst ausführen (siehe unten).After every scan PermLens checks known pitfalls on its own: folders a container sees as “nobody”, missing mount sources, shared folders without setgid, the same name with different numbers, NFS with no_root_squash and more. Every problem comes with an explanation, a command to copy and a rating: harmless, caution or risk. PermLens can carry out many fixes itself (see below).

PrüfenCheck

Kann X hier schreiben?Can X write here?

Container, Benutzer und Ordner wählen. PermLens rechnet aus, ob Lesen und Schreiben klappt, und zeigt den Rechenweg: Besitzer, Gruppe, ACL, Mapping und jeden Ordner auf dem Weg. Eine Gegenprobe fragt im Container als dieser Benutzer nach, ohne etwas zu schreiben. Bei NFS ist sie nur ein Hinweis, deshalb gibt es zusätzlich einen echten Schreibtest. Unter jeder Antwort steht „So geht es“ mit dem passenden Weg.Pick a container, a user and a folder. PermLens works out whether reading and writing will work and shows how it got there: owner, group, ACL, mapping and every folder along the path. A cross-check asks inside the container as that user, without writing anything. With NFS it is only a hint, so there is also a real write test. Below every answer, “How to fix it” shows the matching way forward.

Plus the settings from /etc/pve/lxc/<id>.conf with the important lines explained. A separate page shows every name and number across the host and all containers, with differences at the top.

Sicherheit und BetriebSecurity and operation

Ändert nur mit Erlaubnis, bleibt zu HauseChanges only with permission, stays at home

SicherheitSecurity

PermLens spricht nur über SSH mit dem Proxmox-Host, mit einem eigenen Schlüssel, der ausschließlich ein kleines Wächter-Script aufrufen darf. Das Script lässt nur Befehle aus einer festen Liste durch und protokolliert jeden Aufruf. Ohne deine Freigabe auf dem Host liest PermLens nur. Ändern geht erst, wenn du auf dem Proxmox eine Schalter-Datei mit den erlaubten Containern anlegst. Die Oberfläche ist immer mit Passwort geschützt und nur aus dem Heimnetz erreichbar. PermLens gehört nie ins Internet. Was genau auf dem Host passiert, steht weiter unten.PermLens talks to the Proxmox host only via SSH, using its own key that may do nothing but call a small guard script. The script only lets commands from a fixed list through and logs every call. Without your permission on the host PermLens only reads. Changing only works once you create a switch file on the Proxmox host listing the allowed containers. The interface is always password-protected and only reachable from the home network. PermLens must never be exposed to the internet. Exactly what happens on the host is described below.

SicherheitshinweisSecurity note

Sicherheit ist mir wichtigSecurity matters to me

PermLens bekommt Zugriff auf deinen Proxmox-Host. Deshalb ist es so gebaut, dass es möglichst wenig darf und alles nachprüfbar bleibt:PermLens gets access to your Proxmox host. That is why it is built to be allowed as little as possible and to keep everything verifiable:

  • Wächter statt Vollzugriff: Der SSH-Schlüssel von PermLens darf nur ein kleines Wächter-Script aufrufen. Das lässt nur Befehle aus einer festen Liste durch, prüft bei Änderungen jeden Wert und protokolliert jeden Aufruf.A guard instead of full access: PermLens’ SSH key may only call a small guard script. It only lets commands from a fixed list through, checks every value for changes and logs every call.
  • Geprüfte Einrichtung: Der Einrichtungs-Befehl führt nur ein Script aus, dessen Prüfsumme stimmt. Er lädt es über HTTPS und akzeptiert dabei nur das Zertifikat deines eigenen PermLens.Verified setup: The setup command only runs a script whose checksum matches. It loads it over HTTPS and only accepts the certificate of your own PermLens.
  • Verschlüsselt: Die Oberfläche läuft über HTTPS mit eigenem Zertifikat. Den Fingerabdruck kannst du im Browser prüfen.Encrypted: The interface runs over HTTPS with its own certificate. You can check its fingerprint in your browser.
  • Gehärtetes Image: Kein root im Container, feste Paketversionen mit Prüfsummen, ein festgelegtes Basis-Image, dazu eine Liste aller Pakete (SBOM) und ein Herkunftsnachweis am Image.Hardened image: No root inside the container, pinned package versions with checksums, a pinned base image, plus a list of all packages (SBOM) and a provenance record attached to the image.
  • Ändern nur mit deiner Erlaubnis: PermLens ändert nur, wenn du auf dem Host eine Schalter-Datei anlegst, und nur in den Containern, die du darin einträgst. Jede Änderung mit Vorschau, Protokoll und Rückgängig.Changing only with your permission: PermLens only changes things if you create a switch file on the host, and only in the containers you list in it. Every change with preview, log and undo.

Keine Software ist ohne Risiko. Stelle PermLens nie ins Internet, nutze ein starkes Passwort und schütze deinen Dockhand-Zugang genauso gut, denn wer Dockhand bedienen kann, kann auch den PermLens-Container steuern. Eine Firewall-Anleitung für den PermLens-LXC und alle Einzelheiten stehen in der Sicherheitsbeschreibung.No software is free of risk. Never expose PermLens to the internet, use a strong password and protect your Dockhand access just as well, because whoever can operate Dockhand can also control the PermLens container. A firewall guide for the PermLens LXC and all details are in the security description.

Was PermLens auf deinem Host tutWhat PermLens does on your host

PermLens braucht Zugriff auf deinen Proxmox-Host. Die Sicherheit hängt deshalb nicht davon ab, dass PermLens „brav“ ist: Selbst wer den PermLens-Container komplett übernimmt, darf auf dem Host nur, was das Wächter-Script erlaubt. Dieses Script liegt auf dem Host, gehört root und kann von PermLens aus nicht verändert werden.PermLens needs access to your Proxmox host. That is why security does not depend on PermLens “behaving”: even someone who takes over the PermLens container completely can only do on the host what the guard script allows. That script lives on the host, belongs to root and cannot be changed from PermLens.

EinrichtungSetup

Genau zwei ÄnderungenExactly two changes

  • Ein Befehl in der Proxmox-Shell lädt ein kurzes Script über HTTPS, nur vom Zertifikat deines PermLens (--pinnedpubkey), und führt es nur aus, wenn seine Prüfsumme stimmt.One command in the Proxmox shell downloads a short script over HTTPS, only from your PermLens’ certificate (--pinnedpubkey), and runs it only if its checksum matches.
  • Neu: das Wächter-Script /usr/local/sbin/permlens-guard.New: the guard script /usr/local/sbin/permlens-guard.
  • Eine Zeile mehr in /root/.ssh/authorized_keys. Nichts wird gelöscht oder überschrieben.One extra line in /root/.ssh/authorized_keys. Nothing is deleted or overwritten.
  • Der Befehl gilt eine Stunde und nur einmal.The command is valid for one hour and only once.

Der SchlüsselThe key

Fest an den Wächter gebundenBound to the guard

  • command=: Egal was PermLens schickt, es startet immer nur der Wächter. Eine Shell gibt es nicht.command=: whatever PermLens sends, only the guard starts. There is no shell.
  • restrict: keine Weiterleitungen, kein Terminal.restrict: no forwarding, no terminal.
  • from=: gilt nur von der Adresse des PermLens-LXC aus.from=: only valid from the PermLens LXC’s address.
  • Jeder Aufruf steht im Systemprotokoll: journalctl -t permlens.Every call is logged: journalctl -t permlens.

ErlaubtAllowed

Lesen, feste ListeReading, fixed list

  • Lesen ist immer erlaubt, nach einer festen Liste (Wächter-Script Version 7).Reading is always allowed, from a fixed list (guard script version 7).
  • Container-Liste und -Einstellungen, Benutzer und Gruppen, Mounts, /etc/subuid und /etc/subgid, im Container Samba- und NFS-Einstellungen.Container list and settings, users and groups, mounts, /etc/subuid and /etc/subgid, Samba and NFS settings inside the container.
  • Besitzer und Rechte nur der Ordner, die in Container eingehängt sind, nie deren Inhalt.Owner and permissions of only the folders mounted into containers, never their content.

  • Keine Passwortdateien, kein freier Befehl, Sonderzeichen wirken nicht.No password files, no free-form commands, special characters have no effect.

ÄndernChanging

Nur mit deinem SchalterOnly with your switch

  • Nur im Container, nur in eingehängten Ordnern und unter /home. Nie root, Systemkonten oder Passwörter.Only inside the container, only in mounted folders and under /home. Never root, system accounts or passwords.

  • Mehrere Proxmox: Jeder bekommt sein eigenes Wächter-Script und entscheidet mit seiner eigenen Schalter-Datei, ob PermLens dort ändern darf.Several hosts: each gets its own guard script and decides with its own switch file whether PermLens may change things there.

Ehrliche GrenzenHonest limits

  • PermLens verschlüsselt mit einem selbst erzeugten Zertifikat, der Browser warnt beim ersten Besuch einmal. Wer HTTPS abschaltet oder PermLens über http:// aufruft, verliert den Schutz durch das festgelegte Zertifikat. Dann bleibt nur die Prüfsumme des Scripts.PermLens encrypts with a self-generated certificate, so the browser warns once on the first visit. Turning HTTPS off or opening PermLens via http:// loses the protection of the pinned certificate. Only the script checksum remains then.
  • Wer das PermLens-Passwort hat, hat die Rechte des Wächters: Lesen, und in den Containern aus der Schalter-Datei auch Ändern. Deshalb: starkes Passwort, am besten mit Zwei-Faktor-Anmeldung, nie ins Internet.Whoever has the PermLens password has the guard’s rights: reading, and changing in the containers listed in the switch file. So: a strong password, ideally with two-factor login, never on the internet.
  • Der Hinweis auf neue Versionen fragt alle sechs Stunden die öffentliche Release-Liste bei GitHub ab. Mitgeschickt wird nur die Versionsnummer, keine Daten vom Proxmox. Abschaltbar in den Einstellungen.The new-version notice checks GitHub’s public release list every six hours. Only the version number is sent, no data from the Proxmox host. It can be switched off in the settings.
  • Programme im Container (getent, stat) stammen aus dem Container. Ein manipulierter Container kann falsche Angaben liefern, bekommt dadurch aber keine zusätzlichen Rechte.Tools inside the container (getent, stat) come from the container. A tampered container can report false data but gains no extra rights.
